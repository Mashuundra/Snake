# Змейка — классическая игра в терминале

Классическая игра «Змейка», реализованная на Python с управлением через терминал. 
Игрок управляет змейкой, собирает еду, растёт в длину и старается не врезаться в стены или своё тело.

## Core модуль

Содержит основную игровую логику.

### snake.py — модель змейки

**Класс `Snake`** управляет поведением змейки:

- `move()` — перемещение головы в текущем направлении, удаление хвоста (если не флаг роста)
- `set_direction(dx, dy)` — смена направления с защитой от развороота на 180°
- `grow()` — установка флага для увеличения длины на следующем шаге
- `check_self_collision()` — проверка, не врезалась ли голова в тело

**Алгоритм движения:**
1. Вставить новую голову в начало списка `_body`
2. Если установлен флаг `_grow_flag` — сбросить его и не удалять хвост
3. Иначе удалить последний элемент списка (хвост)

### game.py — игровой движок

**Класс `GameEngine`** связывает змейку, еду и правила игры.

**Основные методы:**

- `update()` — один шаг игры:
  1. Движение змейки
  2. Проверка столкновения со стенами
  3. Проверка столкновения с собой
  4. Проверка съедания еды → рост, увеличение счёта, генерация новой еды

- `_generate_food()` — поиск всех свободных клеток и случайный выбор позиции для еды. Если свободных клеток нет — устанавливается статус `WIN`.

- `reset()` — полный сброс игры (змейка в центр, счёт 0, новая еда)

**Статусы игры (GameStatus):**
- `PLAYING` — игра продолжается
- `GAME_OVER` — поражение (стена или самопересечение)
- `WIN` — победа (всё поле заполнено змейкой)


## UI модуль

Отвечает за отображение игры и ввод пользователя.

### renderer.py

**Класс `GameRenderer`**:

- `_render()` — построение символьного поля:
  - Стены по краям (если `DRAW_WALLS = True`)
  - Еда
  - Голова и тело змейки (разные символы)
- `run()` — основной игровой цикл с пошаговым вводом (после каждой команды нужно нажимать Enter)

**Поддерживаемые клавиши:**
- `W` — вверх
- `S` — вниз
- `A` — влево
- `D` — вправо
- `R` — рестарт после окончания игры
- `Q` — выход


## Config модуль

`config.py` содержит все настройки игры. Изменяя значения здесь, можно настраивать игру без правки кода.

**Размеры поля:**

- DEFAULT_WIDTH = 20
- DEFAULT_HEIGHT = 20
- MIN_WIDTH = 5
- MAX_WIDTH = 50

**Символы для отрисовки:**
- SYMBOL_SNAKE_HEAD = '●'
- SYMBOL_SNAKE_BODY = '○'
- SYMBOL_FOOD = '★'
- SYMBOL_EMPTY = '·'
- SYMBOL_WALL = '#'

### Запуск:
python main.py

### Запуск с пользовательскими параметрами:
python main.py --width 30 --height 20 --speed 15
python main.py -w 30 -H 20 -s 15

### Установка зависимостей:
pip install -r requirements.txt

### Запуск тестов:
pytest tests/ -v

### С покрытием:
pytest --cov=core --cov=ui --cov-fail-under=70
